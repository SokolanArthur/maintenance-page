# 🚧 Maintenance Page (Docker)

Это максимально простой и легковесный Docker-контейнер, который отдает статичную HTML-страницу с текстом «Техническое обслуживание». 

Проект создан в первую очередь как песочница для изучения основ контейнеризации и самостоятельного написания `Dockerfile`. Однако он имеет и практическое применение: этот контейнер можно быстро поднять на сервере и повесить на 80 порт, пока основной проект (например, аналитика или база данных) остановлен для обновлений или деплоя.

## 🛠 Что внутри

* **Базовый образ:** `nginx:alpine` (использован легковесный образ, чтобы контейнер весил всего пару мегабайт).
* **Контент:** Кастомный `index.html`, который подменяет стандартную стартовую страницу Nginx.
